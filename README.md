# 🐦 eBird Data Exploration
*Understanding Bird Observations, Species Distribution, and Trends in Dane County, WI*

---

## 📌 Overview

This notebook explores **[eBird](https://ebird.org/home)** data — one of the world’s largest citizen-science biodiversity platforms developed by the **Cornell Lab of Ornithology**. Our focus is on **Dane County, Wisconsin**, with observations spanning **2015 to 2025**.

As a local birder, I was curious to explore patterns in birding activity and species diversity. This project combines eBird data with climate variables to explore trends and build predictive models.

---
